# Course verticale

Escalade un mur en courant. Avec [le rebord](parcool:actions/hang_on.md) et [le rétablissement](parcool:actions/climb_up.md), tu franchis jusqu'à 5 blocs : c'est le maximum.

## Comment faire

1. Lance une [course rapide](parcool:actions/fast_run.md)
2. Fonce vers le mur en regardant vers le haut et appuie sur <key name="key.jump"/>
