# Atheria Zombie Edition

Modpack Minecraft 1.21.1 (NeoForge 21.1.265) du serveur Atheria, au format packwiz.

Ce depot sert aux mises a jour automatiques : a chaque lancement, l'instance des joueurs
compare ses fichiers avec `pack.toml` et telecharge seulement ce qui a change.

Adresse du pack : https://raw.githubusercontent.com/MikaMsaa/atheria-pack/main/pack.toml

Installation (Modrinth App) : importer le fichier `.mrpack` fourni par Mika, puis dans les
reglages de l'instance > Launch hooks > Pre-launch : `cmd /c .\atheria-maj.bat`
